# AI同志类型探索工具 - 产品重构计划

## 📋 Plan概述

**产品愿景：**
从"AI算命工具"升级为"身份探索平台"

**核心价值观（基于Anthropic理念）：**
1. 透明度优先 - 明确告知用户工具的局限性
2. 隐私至上 - 100%本地处理，零数据收集
3. 自我探索 - 用户主动选择，而非被动接受
4. 教育功能 - 提供文化背景和批判性思考
5. 安全性 - 避免标签化和刻板印象

## 🎭 设计哲学

**基于Anthropic的产品价值观：**

1. **透明度 > 神秘感**
   - 明确告知用户算法原理
   - 不夸大AI能力
   - 强调工具的娱乐性质

2. **用户控制 > AI判断**
   - 用户主动选择
   - 用户可以覆盖结果
   - 用户控制所有数据

3. **教育 > 分类**
   - 提供文化背景
   - 鼓励批判性思考
   - 避免强化刻板印象

4. **隐私 > 功能**
   - 所有处理本地化
   - 零数据收集
   - 用户可随时清除数据
